# Field Lab
Single-file math/physics lab: vanilla JS in one IIFE, three.js r128, optional WebGPU. Build: src/build.py patches src/orig.html, inserts part files, runs ds.py CSS pass -> dist/index.html. Full docs: docs/vault (start at "00 Home"). Design system: docs/DESIGN.md.

## Rules
- Maths, physics, computation stay byte-for-byte unchanged unless asked.
- Every ID, class, data attribute stays.
- No new dependencies or fonts; Potato must not get heavier.
- One desaturated accent, tokens only. WCAG 2.2 AA, 44 px coarse hit areas, motion 120-250 ms.
- Phone-first (~390 px).

## Style
Talk less, don't explain code unless asked. Minimal comment-free code, {} on all if/for, targeted edits over rewrites. User writes Czech or English.
