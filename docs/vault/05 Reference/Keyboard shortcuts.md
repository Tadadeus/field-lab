# Keyboard shortcuts

From the `KEYS` table (press **?** in the app). Handler: one `keydown` listener near `keysShow`; it ignores keys while typing in text inputs.

| key | action |
|---|---|
| Space | play / pause |
| → | one step forward |
| ← | one step backward |
| R | back to the start |
| [ ] | previous / next scene |
| 1 … 9 0 | switch set (Twistor … Law Lab) |
| D | 3D ↔ 4D |
| B | favorite this scene |
| / | search all scenes |
| CtrlZ | undo a settings change |
| CtrlShiftZ or CtrlY | redo |
| S | save a picture |
| V | record a video |
| F | full-screen view |
| , . | timeline: step back / forward |
| C | compare A / B |
| K | save a camera bookmark |
| G | glossary |
| M | sound on / off |
| ? | show this list |
| Esc | close menus and this list |
