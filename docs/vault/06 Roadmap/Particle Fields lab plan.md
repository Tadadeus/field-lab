# Particle Fields lab plan (idea, not built)

**Goal.** See the wave/field of each of the 17 Standard Model particles: 6 quarks, 3 charged leptons, 3 neutrinos, photon, gluon, W, Z, Higgs. Today they exist only as point particles in [[Lab Universe]] with real mass, charge, spin, lifetime and decays.

## Field per family
- **Higgs**: scalar, vev ≈ 246 GeV, ripples on top of the constant background.
- **Fermions**: Dirac spinor; density = brightness, phase = colour, spin = arrow. Neutrino oscillation is the best visual (flavour mixing in time).
- **Quarks**: need a confinement caveat; show them inside a meson or proton.
- **Photon, gluon**: massless vectors with E/B and polarisation; gluon has 8 colours.
- **W, Z**: massive, 3 polarisations; Yukawa e^(−mr)/r versus 1/r for the photon.

## Dynamics
One-particle wave packets with E² = p² + m². Masses span ~10¹², so a log-scale zoom is needed.

## UI
17-tile grid; tap a tile for a big view with sliders; compare mode; illustrative interaction vertices.

## Where
Option A: new lab. Option B: a "Fields" tab in Universe. See [[Open decisions]]. Method base: [[Lab Lattice]] fields.
