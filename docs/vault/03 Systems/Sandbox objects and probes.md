# Sandbox objects and probes

Entity types `ETYPES`: **point, tracer, ray, fline, link, sphere, twistor**.

- point: a source; tracer: a particle that follows the field; ray: a light-like line; fline: a field line; link: a connection between two entities; sphere: a probe surface (flux); twistor: a twistor object ([[Lab Twistor]]).
- Add, drag, delete and edit in the `obj` settings tab ([[Settings and app popover]]); edits push [[Undo and redo]] steps.
- Saved with the state and included in [[Share codes]].
