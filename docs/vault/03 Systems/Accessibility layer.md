# Accessibility layer (`ux.js`)

Target: **WCAG 2.2 AA**.

- Accessible names and roles for icon buttons and custom controls.
- Visible focus ring, keyboard reach for all controls ([[Keyboard shortcuts]]).
- 44 px hit areas on coarse pointers (applied with `:where()` so it adds no specificity).
- Motion 120–250 ms and respects reduced motion.
- Contrast checked in both themes ([[Light theme and data colour]]).
- Graph description button is an open decision ([[Open decisions]]).
- How it is verified: [[Verification tools]].
