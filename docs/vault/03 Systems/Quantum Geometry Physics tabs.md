# Quantum, Geometry and Physics tabs (`qm`, `geo`, `ph`)

Extra demos and readouts layered on the active lab's fields:

- **qm**: quantum views (wavefunction, Bloch spheres, entanglement measures).
- **geo**: geometry views (curvature, Hopf/fibre structure, projections).
- **ph**: physics views (conserved charges, energy, solitons, lattice demos).

Scenes tagged Quantum / Geometry / Physics in [[Scene catalog]] switch these tabs on. Tab list: [[Settings and app popover]].
