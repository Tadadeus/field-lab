# Info icons and sections

- The small **info icon** next to a control or heading opens its entry from the HELP table ([[Help tooltips glossary tour]]).
- Collapsible **sections** group related controls; open/closed state is remembered per section.
- Icons are real buttons with an accessible name and a 44 px coarse hit area ([[Accessibility layer]]).
- Convention: [[Component conventions]].
