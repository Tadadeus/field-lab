# History timeline

- `HS` records snapshots of the state at intervals and at key actions.
- A scrubber lets you jump back to an earlier snapshot and continue from there.
- Distinct from [[Undo and redo]] (action-level) and [[Camera bookmarks]] (view only).
- Memory lives in RAM only; saved states persist via [[State and persistence]].
